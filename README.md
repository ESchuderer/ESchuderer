# Eike Schuderer

Software engineer in Germany. I build TypeScript web apps, APIs and developer tooling, in the open and with AI coding agents as a tool.

Works with: TypeScript, Node.js, React, Next.js, Mantine, Python, build123d.

## Projects

- [BenchKeeper](https://github.com/ESchuderer/BenchKeeper): keeps Claude Code and Codex set up the same way on every machine and repository, with rules, skills and tools at pinned versions that one app installs and checks.
- [OpenReloading Ballistics](https://github.com/OpenReloading/Ballistics): a ballistics database with interior and exterior simulations as a web app and a versioned REST API, with a Pages edition that computes in the browser.
- [BuildGuide](https://github.com/OpenReloading/BuildGuide): interactive build guides from one JSON file (parts list, wiring and tubing boards with a tick per connection) in plain JavaScript, with MkDocs and Docusaurus packages.
- [AutoLever](https://github.com/OpenReloading/AutoLever) and [Feeder](https://github.com/OpenReloading/Feeder): the hardware side, a pneumatic press drive with a build guide, and a parametric brass and bullet collator generated in code with build123d. Both pre-release.
